# WineAndCheesePairingApp

A full frontend React application for managing wines, cheeses, pairings, recommendations, and user administration.

This project was created as the final project for the Frontend Developer program organized by [Edunova School for Adult Education](https://www.edunova.hr/?utm_source=chatgpt.com).

The application was designed to simulate a real-world business-oriented system with:

* CRUD operations
* role-based authentication
* responsive UI
* accessibility features
* dynamic filtering and sorting
* data export functionality
* multiple data sources

---

## Technologies Used

* React
* React Router
* React Bootstrap
* Vite
* JavaScript (ES6+)
* Zod Validation
* Firebase
* LocalStorage API

---

## Main Features

### Wine & Cheese Management

* Create, edit, delete, and view wines and cheeses
* Pairing system for wine and cheese combinations
* Filtering, sorting, and pagination

### Authentication & Roles

* Login and registration system
* Admin and user roles
* Protected routes and role-based UI rendering

### Accessibility Support

* High contrast mode
* Grayscale mode
* Readable font mode
* Adjustable text sizing
* Accessibility menu

### Data & Utilities

* Fake data generation
* PDF and Excel export
* LocalStorage persistence
* Firebase integration
